# CDL Practice Quiz

A free, offline practice quiz for the commercial driver's license (CDL) written test:
air brakes, combination vehicles, and general knowledge (445 questions).

- **No ads, no accounts, no tracking.** The page makes no outside requests.
- **Works offline.** Download one file and open it in any browser. No install.
- **Progress stays on your device.** You can save a backup file and load it on another computer.

## Use it

1. Download `CDL-Practice-Quiz.html` (one file, everything included).
2. Double-click it, or open it in Chrome, Edge, Firefox, or Safari.

Or open `index.html`, which loads the same app from separate files and is easier to edit.

## What it does

- **Practice by subject.** Each subject shows how many questions you have answered and how often you were right.
- **Study mode.** The answer appears as soon as you pick one.
- **Exam mode.** Answers are checked at the end, and a timer shows how long you took.
- **Mock tests.** Timed sets in the usual layout: 25 air brakes, 20 combination vehicles, 50 general knowledge. You pass with 80% of the scored questions. State layouts vary, so check your state's rules.
- **Flags and bookmarks.** Flag a question in a test to review it later. Bookmark any question to practise it again.
- **Questions page.** Search every question and answer, filter by status, and reveal the marked answer.
- **Progress page.** Totals, accuracy by subject, the questions you miss most, recent tests, and backup and restore.
- **Light and dark mode.**

### Keyboard during a test

| Key | Action |
| --- | --- |
| 1, 2, 3 | Answer |
| Right arrow | Next question |
| Left arrow | Previous question |
| F | Flag or unflag |
| S | Bookmark or unbookmark |

## Files

| File | What it is |
| --- | --- |
| `index.html`, `style.css`, `app.js`, `store.js` | The app, as separate files for editing |
| `questions.js` | The question bank (one question per line) |
| `store.js` | Saves progress in the browser and handles backups |
| `CDL-Practice-Quiz.html` | Single-file build, generated by `build.js` |
| `build.js` | Rebuilds the single file from the parts above |
| `tests/check-questions.js` | Checks the question bank for broken entries |
| `tests/browser-test.cjs` | Runs the app in a real browser (needs Playwright) |

## Develop

```bash
node tests/check-questions.js   # question bank checks
node build.js                   # rebuild CDL-Practice-Quiz.html
node tests/browser-test.cjs     # full browser test (needs Playwright; set PLAYWRIGHT_PATH if needed)
```

## Question bank notes

- Questions and answers come from three study files (air brakes, combination vehicles, general knowledge), using the answers marked in those files.
- Exact repeats are removed (one copy kept).
- Garbled text left over from editing the study files was rewritten to read cleanly. The meaning of each question and answer was kept.
- Two questions have no marked answer. They are shown but not scored.
- Two pairs of questions are in the bank with conflicting marked answers. Both are kept as they are in the source until someone checks them against the official manual:
  - "When coupling, the proper position of the fifth wheel is" (`combination-vehicles-60` and `combination-vehicles-76`)
  - "Off-ramp that curves downhill" (`general-knowledge-76` and `general-knowledge-132`)
